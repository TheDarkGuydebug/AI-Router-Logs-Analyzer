# AI-Router-Logs-Analyzer-
A local Python-based PCAP analysis workbench for broadband, CPE and network troubleshooting. PCAP Insight v1.5 uses TShark/Wireshark packet data to automatically analyze PPPoE discovery, PPP/LCP, authentication, IPCP, DHCP, DNS, TCP and other common protocols, presenting results through structured summaries and protocol flow ladders.
